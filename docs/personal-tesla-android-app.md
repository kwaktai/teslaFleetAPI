# 개인용 테슬라 안드로이드 앱 메모

상용화하지 않고 **본인 차량만**. 폰은 **차에 상주**.

## 확정

| 항목 | 결정 |
|---|---|
| 배포 | 사이드로드. **플레이스토어 등록 없음** |
| 형태 | **안드로이드 앱** (상주 · 부팅 자동시작 · 화면 유지) |
| 과속카메라 · 주행 방향 | **카카오내비 앱으로 확정**. 공공데이터/`/speedcam`으로 자체 판정하지 않음 |
| 전방 휴게소 · 충전소 | **우리 앱** + 카카오 로컬 검색 |
| 충전기 가능 대수 | **환경부 KECO** `getChargerStatus` (`stat=2` 충전대기). 1~2분 주기 |
| Tesla BLE / 폰 키 | 안 씀 |
| 차 속도·위치 Fleet/CAN | 1차에 안 씀 |

역할:

```
부팅
  → 우리 앱 자동 시작 (화면 켜둠)
  → 카카오내비 실행 (카메라·맵매칭·방면)
  → 우리 앱은 전방 휴게소 / 충전소만
```

테슬라 화면은 길 안내, 상주 폰은 카카오내비 단속 경고 + 휴게소/충전.  
카카오내비는 **목적지 없이 안전운행(카메라)만** 켜도 된다. 길을 두 번 넣지 않는다.

---

## 왜 앱인가

브라우저 `/speedcam`은 자동시작·절전 예외·카카오내비 실행을 못 한다.  
상주 폰은 시동 후 아무 조작 없이 떠 있어야 하므로 네이티브 앱이 맞다.

앱이 **하지 않는 것:** 자체 과속 판정. 방향 오탐을 피하려고 카카오내비로 넘긴 부분이다.

---

## 앱이 할 일 (1차)

1. 부팅 완료 후 자동 실행 (`BOOT_COMPLETED`, 배터리 최적화 제외)
2. 화면 꺼짐 방지
3. 카카오내비 실행 (패키지 인텐트). 미설치면 안내
4. 폰 GPS로 현재 좌표 → 카카오 `keyword.json`
   - `휴게소` + 반경 → 진행 방향만
   - 그 좌표 근처 `전기차충전소` 또는 `OL7`
5. 큰 글씨로 다음 휴게소 · 충전 여부만 표시

Play 등록 없음. Android Studio → APK → 그 폰만 설치.

---

## 카카오 분담

| 기능 | 어디 |
|---|---|
| 과속·구간·이동식·방면 | **카카오내비 앱** (API 없음) |
| 휴게소 이름·좌표 | 카카오맵 REST `query=휴게소` |
| 충전소 이름·좌표 | `query=전기차충전소` / `OL7` |
| 몇 대 비었는지 | **환경부 KECO** (아래) |

맵 REST를 켠다고 맵매칭·카메라 DB가 생기지 않는다. 그건 내비 앱 쪽이다.

---

## 환경부 KECO 충전 현황

가져오기 **어렵지 않다.** 공공데이터포털 가입 →  
[한국환경공단_전기자동차 충전소 정보](https://www.data.go.kr/data/15076352/openapi.do) 활용신청(개발·운영 자동승인) → `ServiceKey` 하나.

| API | 주소 | 주는 것 |
|---|---|---|
| 정보 | `.../EvCharger/getChargerInfo` | 충전소명, 주소, 위경도, 충전기 목록, 급속/완속 |
| 상태 | `.../EvCharger/getChargerStatus` | 충전기별 `stat`, `statUpdDt` |

`stat` 값:

| 값 | 의미 |
|---|---|
| 2 | **충전대기** ← 사용 가능으로 셈 |
| 3 | 충전중 |
| 1 | 통신이상 |
| 4 | 운영중지 |
| 5 | 점검중 |
| 9 | 상태미확인 |

전방 휴게소 한 줄은 이렇게 만든다.

```
총 N대 = 그 휴게소에 매칭된 충전기 수
사용가능 M대 = stat == 2 인 수
표시: 안성휴게소(서울방향)  충전 3/8
```

**실시간인가:** 초 단위 웹소켓은 아니다. 충전기 상태가 **대략 1~2분**마다 갱신된다. 휴게소 안내에는 충분하다. `period`(1~10분)로 최근 갱신분만 받을 수 있다.

**카카오보다 불편한 점:** 반경 검색이 없다. 시도코드(`zcode`)·충전소ID(`statId`) 기준이다.  
그래서 NAS에서 `getChargerInfo`를 받아 두고, 카카오 휴게소 좌표/이름으로 **가까운 충전소**를 묶은 뒤 `getChargerStatus`만 폴링하는 편이 낫다.

주의:

- 통신이상(1)은 “사용 가능”에 넣지 말 것
- 회원 전용(`limitYn`)은 따로 표기
- 테슬라 슈퍼차저는 KECO에 없거나 늦게 들어올 수 있음. 고속도로 휴게소 급속(환경부·한전·민간)은 대체로 있음
- 개발 키 트래픽은 하루 1,000회. 상주 폰이 10초마다 전국을 치면 부족하다. **휴게소 몇 곳의 statId만** 1~2분에 한 번씩, 가능하면 NAS가 대신 호출

## 하지 않을 것

- 플레이스토어 공개
- Tesla BLE 폰 키
- `/speedcam` 자체 카메라 판정 (방향 오탐 회피용으로 폐기)
- 착좌/에어백 우회
- 과속 회피 조장 UI
