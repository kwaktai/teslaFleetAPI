# 개인용 테슬라 안드로이드 앱 메모

상용화하지 않고 **본인 차량만** 쓰는 개인 앱.

## 결론: 플레이스토어 등록은 필수가 아님

개인용으로 본인 폰에만 설치하면 **Google Play 앱 등록은 하지 않아도 됩니다.**

| 배포 방식 | Play 등록 | 설명 |
|---|---|---|
| APK 직접 설치 (사이드로드) | 불필요 | 폰에서 `알 수 없는 출처` 허용 후 APK 설치 |
| USB / Android Studio 실행 | 불필요 | 개발 중 가장 단순 |
| 내부 테스트 / 비공개 트랙 | 필요 | 다른 기기·계정에 나누어 줄 때 |
| 플레이스토어 공개 출시 | 필요 | 상용·불특정 다수 배포. 이번 용도와 무관 |

Play 개발자 계정(등록비)은 **스토어에 올릴 때만** 필요합니다. 개인 APK에는 없습니다.

카카오맵 API, Tesla 개발자 앱, BLE 권한은 플레이스토어와 **별개**입니다. 스토어에 안 올려도 카카오 개발자 키는 발급받을 수 있습니다.

---

## 목표

내 테슬라와 **BLE**로 연결해서 아래를 보고, 카카오맵 등 외부 API와 합친다.

- 내비게이션 **현재 목적지**
- 드라이브 상태 (P/D/R 등)
- 속도
- 위치
- 카카오맵 API로 **현재 위치 전방 과속단속 카메라** 및 기타 API

---

## 기능 초안

| 구분 | 내용 | 데이터 후보 |
|---|---|---|
| 차량 BLE | 폰–차 근접 연결 | Tesla phone-key / VCSEC BLE |
| 목적지 | 차에 설정된 내비 목적지 | Fleet API `drive_state` / GUI / 내비 필드. BLE만으로는 공식 공개 스펙이 적음 |
| 드라이브 상태 | 기어, 주행 여부 | Fleet API `shift_state`, `drive_state` |
| 속도 | 현재 속도 | Fleet API `speed` 또는 CAN (이미 T-2CAN listen) |
| 위치 | 위도/경도 | Fleet API `latitude`/`longitude` 또는 폰 GPS |
| 과속카메라 | 전방 단속 지점 | 카카오맵/로컬 과속 데이터 + 현재 위치·헤딩 |

## 데이터 경로 (개인용 현실 안)

BLE만으로 목적지·속도·위치를 모두 받는 공식 문서는 거의 없습니다. Tesla BLE는 주로 **폰 키(잠금/해제/시동 권한)** 입니다.

개인용이면 아래처럼 **역할을 나누는 것**이 현실적입니다.

1. **이미 있는 Fleet API 서버** (`teslaFleetAPI`)  
   목적지, `drive_state`, 속도, 위치 조회
2. **폰 BLE**  
   차 근처인지, 폰 키 세션, 근접 UX
3. **카카오맵 REST/SDK**  
   지도, 검색, (허용되는 범위의) 주변/경로 정보
4. **T-2CAN** (선택)  
   차 안 로컬에서 속도·기어 등 Vehicle CAN 수신. 앱과는 Wi-Fi/시리얼 브리지가 따로 필요

과속카메라는 카카오맵 “공식 과속카메라 API”가 항상 있는 것이 아닙니다. 카카오 로컬/길찾기 응답 필드, 또는 이미 서버에 있는 `/speedcam` 데이터를 앱이 호출하는 방식이 더 맞습니다.

## 안드로이드 개발 메모

- 언어: Kotlin
- 최소 설치: Android Studio → 실기기 USB 디버깅 → Run
- BLE: `BLUETOOTH_CONNECT`, `BLUETOOTH_SCAN`, (구버전) 위치 권한
- 위치: `ACCESS_FINE_LOCATION`
- 백그라운드에서 차 상태를 계속 보려면 포그라운드 서비스 검토
- Tesla 계정 토큰은 앱에 하드코딩하지 말고, 기존 NAS Fleet 서버를 호출

---

## 카카오맵 API

- [Kakao Developers](https://developers.kakao.com/)에서 앱 생성 후 REST/네이티브 키 발급
- 개인·비영리 테스트는 보통 키만으로 시작 가능
- 키를 GitHub/APK에 평문으로 올리지 말 것
- 이용약관상 지도 데이터 재배포·상용 내비게이션 대체는 제한될 수 있음. 개인 화면 표시 용도로 유지

## 하지 않을 것

- 플레이스토어 공개 등록
- 타인 차량 제어
- 착좌/에어백 등 안전 장치 우회
- 과속 회피 조장 UI (안내용만)
